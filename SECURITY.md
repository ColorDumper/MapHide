# Security

MapHide updates itself from this repository's releases, so a security problem matters even when it looks small.

## Reporting a problem

Please don't open a public issue. Use **Report a vulnerability** on the [Security tab](https://github.com/ColorDumper/MapHide/security) instead, which only the maintainer can see. Say what you found, which version of MapHide it affects (shown next to the name at the top of the window), and how to reproduce it.

You'll get a reply as soon as possible. Fixes go out as a new release, and the in-app updater offers it to everyone.

## Supported versions

Only the latest release gets fixes.
